# Skill: accelerator batch
Read a count of companies from the accelerator's own directory or batch announcement.
- "Current batch" means the most recently announced cohort; name the cohort in the quote ("Fall 2026 class: 12 companies").
- Use the accelerator's own page, directory or announcement. A news article is acceptable only when it quotes the accelerator's number.
- For a topic count (for example AI companies), count only when the page states the number; do not classify companies yourself.
- If the page lists companies without stating a total and the list is complete on the page, the total is the number of listed companies; say "counted from the list" in the quote. Otherwise return null.
