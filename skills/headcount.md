# Skill: headcount
Read how many people work at the company.
- Use a count or a stated range's lower bound only when the page gives one clearly ("about 300 employees", "team of 120"). Name the source and its date in the quote.
- Prefer the company's own statement (about page, careers page, press release) over a directory estimate.
- A range such as "201-500 employees" is not one number: return null unless the question asks for the range.
- Never count faces on a team page or infer headcount from open roles.
