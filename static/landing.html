How it works

From a typed question to a number you can trust.

01Ask

Type the question the way you'd ask a colleague. No setup, no selectors, no scraper to maintain.

02Match or create

If the catalog already tracks it, you get the tile with its full history at once. If not, Tally finds the source and starts.

03Watch

A monitor re-checks every metric in the background. You only hear about what moved.

04Open the evidence

Every value links to the page and the quote it came from. If a value isn't on the page, the tile says “no value yet”. Tally never guesses.

Two kinds of metric

Reading a number is easy. Counting things is the hard part.

Search results change from run to run, so the size of one result list is not a count. Tally keeps a ledger.

Built on Telem AI

Telem is the engine, and the trace panel shows it.

Search finds sources and entries across providers, with Tavily pinned for entry-finding. Fetch reads the pages. Monitors re-check on a schedule and feed the change log. Every call, provider and latency is logged and shown in the app.
