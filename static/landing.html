How it works

From a typed question to a number you can trust.

01Ask

Type a company, an accelerator or a question, the way you'd ask a colleague. No setup, no scraper to maintain.

02Match or create

If the catalog already tracks it, you get the tile with its full history at once. If not, Tally finds the source and starts.

03Watch

A monitor re-checks every metric in the background. You only hear about what moved.

04Open the evidence

Every value links to the page and the quote it came from. If a value isn't on the page, the tile says “no value yet”. Tally never guesses.

Every number is a recipe

Read one value, count a ledger, or add up a whole sector.

Search results change from run to run, so the size of one result list is not a count. Tally keeps a ledger of entries, each stored once by its link, and reduces it to one number.
